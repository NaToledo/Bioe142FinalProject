**Using Neural Networks to Predict ANI-1 Molecular Energies**

Recent developments in computational algorithms and data processing have pushed machine learning to the forefront as a critical tool in molecular biology and chemistry research. It has a wide range of applications, especially in protein modeling, genomics, and metabolomics, presenting more accurate, comprehensive models for complex biological systems.1 This is especially important for modeling large chemical datasets,2 for which it would be otherwise impossible to predict the behavior for all possible permutations. One such application is in the prediction of molecular energy. Traditional models rely on quantum-chemical calculations. Machine learning accomplishes this on a wider scale at reduced computational cost.
The use of neural networks to model potential energy surfaces using density-functional theory, or DFT, was pioneered by Behler and Parrinello 3 and refined into ANAKIN-ME, or ANI, by Smith et al.4 This project builds upon the findings by Smith et al. as we attempt to build an artificial neural network that will accurately predict the molecular energies of organic molecules.
